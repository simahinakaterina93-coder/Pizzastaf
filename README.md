#  Пицца кота Стафчика

> Веб-сайт для заказа пиццы с милым дизайном, корзиной покупок и системой скидок

---

##  О проекте

**«Пицца кота Стафчика»** — это мини-интернет-магазин пиццы с очаровательным кошачьим дизайном. Проект выполнен на чистом HTML, CSS и JavaScript без использования фреймворков.

###  Возможности

| Функция | Описание |
|---------|----------|
| 🍕 **Просмотр меню** | 8 уникальных видов пиццы с описанием и ценой |
| 🛒 **Корзина покупок** | Добавление, удаление, изменение количества товаров |
| 💾 **Сохранение данных** | Корзина сохраняется в `localStorage` |
| 🚚 **Умная доставка** | Расчёт скидки и стоимости в зависимости от расстояния |
| 📝 **Оформление заказа** | Форма с валидацией и подтверждением |

## Особенности проекта

###  Дизайн и пользовательский интерфейс

| Особенность | Описание |
|-------------|----------|
| **Уникальный кошачий стиль** | Милые названия пицц, эмодзи кота 🐱 и атмосферный дизайн |
| **Градиентный фон** | Красивый фиолетово-синий градиент на главной странице |
| **Hero-блок с фоном** | Визуально привлекательный баннер с призывом к действию |
| **Плавные анимации** | Эффекты при наведении на карточки пицц и кнопки |

###  Функционал корзины

| Особенность | Описание |
|-------------|----------|
| **Выезжающая корзина** | Корзина появляется сбоку, не перезагружая страницу |
| **Оверлей-затемнение** | При открытии корзины фон затемняется для фокуса |
| **Изменение количества** | Кнопки + и - для изменения количества товаров |
| **Автоматический пересчёт** | Стоимость обновляется мгновенно |
| **Сохранение в localStorage** | Корзина не пропадает после закрытия браузера |

###  Умная система скидок

| Особенность | Описание |
|-------------|----------|
| **Динамический расчёт** | Скидка зависит от расстояния доставки |
| **Авто-обновление** | При изменении расстояния цены пересчитываются сразу |
| **Визуальные подсказки** | Бейджики со скидками и бесплатной доставкой |
| **Порог бесплатной доставки** | При заказе от 1500 ₽ доставка бесплатно |

###  Форма заказа

| Особенность | Описание |
|-------------|----------|
| **Валидация полей** | Проверка заполнения обязательных полей |
| **Выбор способа оплаты** | Карта онлайн, наличные, карта курьеру |
| **Комментарий к заказу** | Возможность указать детали (домофон, этаж) |
| **Подтверждение заказа** | Модальное окно с благодарностью |
