Пицца кота Стафчика



&#x20;веб-сайт для заказа пиццы с милым дизайном, корзиной покупок и системой оформления заказа.

Проект выполнен на чистом HTML, CSS и JavaScript без использования фреймворков.



&#x20;О проекте



«Пицца кота Стафчика» — это мини-интернет-магазин пиццы, где пользователь может:



просматривать меню пицц;

добавлять товары в корзину;

изменять количество товаров;

оформлять заказ;

получать скидку в зависимости от расстояния доставки;

сохранять корзину через localStorage.

&#x20;Основные страницы

index.html



Главная страница сайта:



красивый hero-блок;

меню пицц;

корзина с боковой панелью;

добавление товаров в корзину;

сохранение данных в браузере.

order.html



Страница оформления заказа:



отображение состава заказа;

расчёт скидок;

расчёт доставки;

форма клиента;

подтверждение заказа.

&#x20;Используемые технологии

HTML5

CSS3

JavaScript (Vanilla JS)

LocalStorage API

Функционал

&#x20;Корзина

добавление товаров;

изменение количества;

удаление товаров;

автоматический пересчёт суммы.

Доставка



Система автоматически рассчитывает:



скидку;

стоимость доставки;

итоговую сумму.

Скидки:

Расстояние	Скидка

До 3 км	15%

3–5 км	5%

Более 5 км	Без скидки

Доставка:

Бесплатно при заказе от 1500 ₽

Иначе стоимость зависит от расстояния.
