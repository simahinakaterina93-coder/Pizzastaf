###  Как добавлять новые пиццы
## Шаг 1: Добавить объект в массив pizzas
Откройте index.html, найдите массив pizzas и добавьте новый объект:

    const pizzas = [
    // ... существующие пиццы
    { 
        id: 9,  // Следующий номер
        name: "Название пиццы на русском",
        originalName: "Original Name",
        description: "Описание ингредиентов и вкуса",
        price: 500,
        image: "images/название_файла.jpg"
    }
    ];
## Шаг 2: Добавить изображение
Положите файл изображения в папку images/ с указанным именем.

## Шаг 3: Проверка
Откройте index.html — новая пицца должна появиться в меню.

## Совет: Изображения рекомендуется использовать одинакового размера (300×200px) для единообразия.

###  Как изменять стили
# Цветовая схема
Основные цвета находятся в <style> блоке каждого HTML-файла:

    /* Основной акцентный цвет */
    #ff6b6b  /* Розово-красный — кнопки, цены */

    /* Фон главной страницы */
    linear-gradient(135deg, #667eea 0%, #764ba2 100%)

    /* Тёмный фон хедера */
    rgba(0, 0, 0, 0.9)
# Как поменять цвета:
    Найдите #ff6b6b в коде

    Замените на нужный HEX-код, например #ff5722

    Сохраните файл и обновите страницу


###  Отладка и решение проблем
- Частые проблемы и их решение
- Проблема	Возможная причина	Решение
- Пиццы не отображаются	Ошибка в массиве pizzas	Проверьте консоль (F12)
- Изображения не грузятся	Неправильный путь к файлу	Проверьте папку images/
- Корзина не сохраняется	Ошибка в localStorage	Очистите кэш браузера
- Скидка не применяется	Неправильный id поля distance	Проверьте HTML-разметку
- Кнопка "В корзину" не работает	Функция addToCart не найдена	Проверьте глобальную область видимости
## Как открыть консоль для отладки
    Chrome/Edge: F12 → вкладка "Console"
 
    Firefox: Ctrl+Shift+K
